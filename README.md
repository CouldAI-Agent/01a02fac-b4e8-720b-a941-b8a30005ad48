# Photo Gallery App

A beautiful, responsive photo gallery application built with Flutter.

## Features
- **Responsive Layout**: A dynamic grid layout that adapts perfectly to mobile, tablet, and desktop screen sizes.
- **Hero Animations**: Smooth, seamless transitions from thumbnail grid to full-screen photo views.
- **Interactive Viewer**: Interactive image viewer supporting zoom and pan gestures.
- **Cross-Platform**: Works beautifully on iOS, Android, Web, Desktop, and macOS.

## Tech Stack
- Framework: Flutter
- Language: Dart

## Setup and Run
1. Ensure Flutter is installed on your machine.
2. Run `flutter pub get` in the root directory to fetch dependencies.
3. Run `flutter run` to launch the application on your preferred device or emulator.
